# 🎮 Simon Says Game

This is a browser-based Simon Says memory game built using HTML5, CSS3, and JavaScript. The game challenges players to remember and repeat an increasingly longer sequence of colors and sounds. This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and game logic.

## Technologies Used

HTML5 – for page structure  
CSS3 – for styling and layout  
JavaScript – for game logic and interactivity

## Features

- Interactive Simon Says gameplay
- Random sequence generation
- Increasing difficulty with each level
- User input validation
- Game-over functionality
- Level tracking
- Interactive button animations
- Responsive design for different screen sizes
